# Inter 4.1

Fuentes OTF estáticas del [release oficial v4.1 de rsms/inter](https://github.com/rsms/inter/releases/tag/v4.1), archivo `Inter-4.1.zip`, directorio `extras/otf/`.

Se incluyen únicamente los cinco pesos de SPEC §1.2. Se verificó que el nombre de cada archivo coincide con su PostScript name (registro 6 de la tabla OpenType `name`):

- Inter-Regular
- Inter-Medium
- Inter-SemiBold
- InterDisplay-SemiBold
- InterDisplay-Bold
